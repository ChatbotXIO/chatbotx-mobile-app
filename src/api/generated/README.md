Generated by `pnpm generate:api` (scripts/generate-api-client.ts) from the ChatbotX builder's
OpenAPI spec (`{API_BASE_URL}/api/spec.json`, the full oRPC router spec — override with
`API_SPEC_PATH=/api/public-spec.json` for the workspace-token-only surface instead). Do not
hand-edit files in this directory — they are overwritten on every regeneration.

`schema.ts` is committed so the app builds without a live backend available. Re-run
`pnpm generate:api` against a running ChatbotX builder instance to refresh it after backend API
changes.
